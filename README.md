# アンケート分析支援ツール 最終版

## 起動
- Windows: `start-server.bat`
- macOS / Linux: `start-server.sh`
- ブラウザ: `http://localhost:8000/`

## 主な補強
- Googleフォーム印刷PDFの文字・設問・選択肢解析
- `1.20代` から先頭整数 `1` のみを抽出し数値順に整列
- 引用符・カンマ・セル内改行に対応したCSV解析
- 一時保存と再開
- 設問別・全設問の対応表入出力
- 入力20MB制限、PDF.jsの動的評価無効化
- CSV/Excel数式注入への簡易対策

公開表示、OSSライセンス、画像、関連リンク、お知らせデータを含む全ファイル一式です。

## MAの1・0と欠測値の最終ルール
- 有効な複数回答では、選択した選択肢を `1`、選択しなかった選択肢を `0` とします。
- 例: 選択肢1～4のうち1と2を選択した場合は、`1, 1, 0, 0` と出力します。
- 回答そのものが未回答、空文字、空白文字だけの場合は、展開されたすべての枝番を `.` とします。
- 正規の選択肢にない値を含むなど、回答にエラーがある場合は、展開されたすべての枝番を `.` とします。
- 「その他」を欠測扱いに設定した場合は、その回答の展開列をすべて `.` とします。
- `0` は「回答は行われたが、その選択肢は選ばれなかった」ことを表します。欠測ではありません。

## V0 ID番号
- 「変数名設定」画面で、ID番号を付けるか選択できます。
- 初期状態ではID番号を付ける設定です。
- ID番号を付ける場合、加工後データの先頭列を `V0` とします。
- 値は回答の現在の並び順に従って `1, 2, 3, ...` と付与します。
- ID番号を付けない場合、`V0` 列は作成せず、通常の設問は従来どおり `V1` から始まります。
- 一時保存にはID番号の使用設定も含まれます。


## 簡易分析ページ
- 加工済みデータと対応表Excelを読み込みます。
- MAは `V5-1`、`V5-2` を別設問にせず、`V5`としてまとめます。
- SAの初期グラフは円、MAは横棒です。
- V0はIDのため分析対象外です。
- 設問別・全設問のExcel、CSV、PNG出力に対応します。
